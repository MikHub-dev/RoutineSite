# RoutineSite
Rituel de 30 minutes par jour sur un sujet à approfondir

## Routine « Fluidité verbale » (POC)
`parole.html` : jour 1 d'une routine orale (association de mots 60 s + discours de 2 min), mesures de voix faites dans le navigateur (Web Audio + reconnaissance vocale de Chrome). Accès par le même code élève que le reste du site. Le bilan généré est copié-collé à Claude pour le retour du jour.
